# DedeKorkutHF 🐺

## About

DedeKorkutHF Is A Hugging Face Project Focused On Exploring And Applying Modern AI Technologies Through Practical Projects.

This Repository Contains Hands-On Exercises And AI Projects Developed During The Hugging Face Learning Journey.

## Project

### ParasitoVision 🦠

ParasitoVision Is A Computer Vision Project For Detecting Intestinal Parasites In Microscopy Images Using A YOLO11n-Based Object Detection Model.

The Project Demonstrates How A Custom-Trained YOLO Model Can Be Integrated Into A Web-Based Interface And Deployed Through Hugging Face Spaces.

## Model

- Model: YOLO11n
- Task: Object Detection
- Application: Intestinal Parasite Detection
- Input: Microscopy Images
- Model Format: `.pt`
- Version: V1.0.0

## Technologies

- Python
- PyTorch
- Ultralytics YOLO
- Hugging Face
- Hugging Face Spaces
- HTML
- CSS
- Google Colab

## Features

- Microscopy Image Analysis
- Intestinal Parasite Detection
- YOLO-Based Object Detection
- Lightweight YOLO11n Model
- Web-Based Visualization
- Hugging Face Spaces Deployment

## Training

The Model Was Developed And Trained Using Google Colab.

The Training Workflow Included Dataset Preparation, Model Training, Evaluation, And Exporting The Final YOLO Model For Deployment.
